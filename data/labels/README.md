# Labels

Labels YOLO-seg obtidas do repositório: um `.txt` por imagem, com o mesmo nome da imagem (por exemplo `CDY_2015.txt`). Os arquivos **não são versionados** neste repositório.

Formato de cada linha: `classe x1 y1 x2 y2 ... xn yn`, com coordenadas normalizadas entre 0 e 1 e classe `0` (cacho de uva).

No notebook `uva_testes_bagas.ipynb`, esta pasta corresponde a `E:\Projeto_Uva\datasets\wgisd\labels`.

Origem: https://github.com/thsant/wgisd (pasta data/), licença CC BY-NC 4.0.
